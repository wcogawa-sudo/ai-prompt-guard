AI Prompt Guard

Lab settings. Fields set by your organisation's enterprise policy are locked and shown greyed out.

Status

Log collector

Warnings

On: the user sees what was found and confirms before the redacted prompt is sent. Off: everything is redacted silently with a small "Protected" notice. Blocks apply either way.

Names to always protect

One full name per line (e.g. managers, staff, clients). These are always redacted, in any capitalisation. In production this list comes from the org's directory via policy.

Keep encrypted originals (for admin review)

Paste the block printed by npm run evidence -- keygen. Originals are then encrypted on this device with that public key; only the private key holder can read them. Leave empty to keep originals off.

Policy override (JSON)

Leave empty to use the bundled default policy. Invalid JSON is ignored and the default stays in force.
